# FanDuel Sports Betting Analysis

## **Overview**

This project is an exercise using sample sports betting data to uncover insights around retention, seasonality, and bettor segments.  

The end goal is to surface data-driven opportunities for cross-selling customers into additional products across the company’s ecosystem.
